# 🚀 Инструкция по сборке CHATOX AI v0.7.0 (Windows .exe / Portable и Android .apk)

Добро пожаловать! Версия проекта обновлена до **v0.7.0**. Ниже представлена подробная инструкция по компиляции под Windows и Android с поддержкой кастомных иконок приложения и установщика (`Setup`).

---

## 🪟 Часть 1. Сборка для Windows (.exe, Portable и Установщик v0.7.0)

### Шаг 1. Подготовка иконок `.ico`
Поместите ваши иконки в папку `assets/`:
1. Главная иконка приложения: **`assets/icon.ico`**
2. Иконка инсталлятора Setup: **`assets/setup-icon.ico`**

### Шаг 2. Установка зависимостей
Откройте командную строку (`cmd` или PowerShell) в папке проекта и выполните:
```bash
npm install
```

### Шаг 3. Сборка исполняемых файлов Windows
Выполните команду сборки:
```bash
npm run build:win
```

🎉 **Результат**: В папке **`release`** появятся готовые файлы для версии **v0.7.0**:
- **`CHATOX AI Setup 0.7.0.exe`** — установщик с вашим значком Setup.
- **`CHATOX AI 0.7.0 Portable.exe`** — портативная версия.

---

## 📱 Часть 2. Сборка для Android (.apk v0.7.0)

Для сборки под Android используется **Capacitor**. Вы можете использовать **Android Studio** или лёгкие **Command Line Tools** (без тяжелой IDE).

### Вариант А: Сборка через Android Studio (С графическим интерфейсом)
1. Выполните в терминале:
   ```bash
   npm run cap:android
   ```
2. Откроется Android Studio:
   - Дождитесь синхронизации Gradle.
   - В верхнем меню выберите **Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)**.
   - Нажмите **Locate** в правом нижнем углу и заберите готовый `.apk` файл.

### Вариант В: Автоматическая сборка через GitHub Actions (В облаке, без установки Android SDK)
Если у вас нет Android SDK, вы можете собрать `.apk` автоматически через GitHub абсолютно бесплатно и без установки тяжелых утилит:
1. Создайте репозиторий на GitHub и загрузите туда ваш проект (`C:\CHATOXAI2.2.0`).
2. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
3. GitHub автоматически запустит сборку (благодаря файлу `.github/workflows/build-apk.yml`, который уже добавлен в проект).
4. Когда сборка завершится (зеленая галочка), нажмите на нее, прокрутите вниз до раздела **Artifacts** и скачайте готовый архив с `app-debug.apk`!

## 💡 Полезные команды (`package.json` v0.7.0):
- `npm run build:win` — Сборка Windows `.exe` / Portable.
- `npm run cap:sync` — Синхронизация веб-кода с Android.
- `npm run dev` — Запуск локального сервера разработки.
